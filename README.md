#Voice Assistant

About the Project

Voice Assistant is a smart productivity application designed to help students manage their studies and daily activities more efficiently.

The application supports voice-to-text and text-to-voice conversion, audio recording, transcription, translation, summarization, and text polishing.

It also provides reminders for important tasks and activities, helping students stay organized, remember deadlines, and improve their learning experience.

Features

1. Voice and Text Conversion

- Convert speech into text using Speech-to-Text (STT).
- Convert text into speech using Text-to-Speech (TTS).
- Listen to generated voice output.

2. Audio Recording

- Record voice and audio.
- Save recordings for future use.
- Convert recorded audio into text.

3. Transcription

- Transcribe audio recordings into readable text.
- Make spoken information easier to review and understand.

4. Translation

- Translate text into different languages.
- Support students in understanding foreign-language content.

5. AI Summarization

- Summarize long text into shorter and clearer information.
- Help students review important points quickly.

6. Text Polishing

- Improve grammar and sentence structure.
- Make writing clearer, more professional, and easier to understand.

7. Smart Reminders

- Set reminders for important tasks.
- Receive notifications for study activities and deadlines.
- Help students remember their daily responsibilities.

8. Student Productivity

- Support students in managing study-related tasks.
- Improve time management and organization.
- Help students become more productive in their daily learning activities.

Technologies Used

Backend

- Java
- Spring Boot

APIs and Services

- ElevenLabs API – Text-to-Speech and voice-related services
- Groq Cloud API – AI-powered text processing
- MyMemory Translation API – Text translation
- Google APIs – Google-related services and integrations
- Firebase Cloud Messaging (FCM) – Push notifications and reminders
